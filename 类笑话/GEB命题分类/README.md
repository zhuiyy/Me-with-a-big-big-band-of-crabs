## GEB命题分类

#### 导语🏝️
关于GEB命题, 我现在有两个可能的定义方法. 

- 弱GEB命题定义为: 

        一个命题是GEB的, 若这个命题既不能是真的, 又不能是假的.

- 强GEB命题定义为:
    
        一个命题是强GEB的, 若这个命题既不能是真的, 又不能是假的, 且命题中存在一个代词, 陈述了一个真包含这个代词的对象的信息(自我指涉).

##### 例:
- “这句话是假的” 是一个强GEB命题
- “我从不说真话, 并且今天天气很好” 是一个强GEB命题
### 强假设
    强弱GEB命题定义等价.

### 无意义命题
    一个命题是WYY的, 若这个命题既有可能是真的, 又有可能是假的.

##### 例:
- “这句话是真的” 是一个WYY命题

### GEB命题分类
一般而言, 我们假设强假设成立.

- 第一类GEB命题:

        一个GEB命题是第一类的, 若这个命题自然导出一个WYY命题.
- 第二类GEB命题:

        一个GEB命题是第二类的, 若这个命题不自然导出一个WYY命题.

##### 例:
- “这句话是假的” 自然诱导出 “这句话是真的”, 前者为(强)GEB问题, 后者为WYY问题.

### 自然猜想
    第一类GEB问题自然导出的WYY命题唯一, 或者说, 第一类GEB问题与WYY命题可以构建自然一一映射.

### 洛希瓣猜想

    不存在第二类GEB命题.

可以理解为: 自然导出的WYY命题把GEB命题的真值(意义)破坏并吸收了.
