### Pt.1 
我在大一研学的时候想出了一个极其烂的笑话: '谁是全世界公认的唐人?' 答案是'接叹按', 因为'唐人街探案'.

### Pt.2
我用这个笑话爆了多人, 其中有一个人微笑中透露着眼红, 他还击: '什么会说?' 答案是马, 因为'<马说>唐韩愈'.

### 评价
这个新的笑话为什么更好笑? 先要理解老笑话'烂'的点, 点在于'唐人街探案'纯粹就是一个谐音, 而且'接叹按'并不是一个真实的人物, 这个答案纯粹是凑出来的, 烂的并不精彩. 然而马说烂的非常出色, 他烂在: 第一, 问题不是人话, 没有任何一个正常人会问'什么会说'; 第二, 他的理由是冗余的, '唐韩愈'这三个字纯粹是为了凑数的, 可能是为了呼应'唐人', 令人忍俊不禁.

唐人街探案本质上是一个元笑话, 笑点产生于对笑话提出者幽默感的质疑, 体验'气笑了'. <马说>强化了元笑话的特征.
